# DOM Router setup and review guide

Published guide: https://hj-park-winehouse.github.io/dom-router-useage/

Python receiver source and runnable ZIP, English/Korean setup instructions, and two videos with English captions.

The ZIP contains the complete receiver source and tests. It excludes runtime databases, credentials and business records. The top-level receiver.py is provided for source inspection; extract the full ZIP to run it.
