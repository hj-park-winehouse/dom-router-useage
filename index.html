1. Start the local receiver

1. 로컬 수신 프로그램 실행

  1. Download and extract the ZIP to a writable folder. Install Python 3.10 or later if needed.
  2. Windows: double-click start.cmd. macOS/Linux: run sh start.sh. The first run creates a virtual environment and installs dependencies from PyPI.
  3. Keep the terminal running and open http://127.0.0.1:19494/. No administrator access, DLL, pairing key or extension ID registration is required.

DOM Router requires a separately running receiver to deliver events. GitHub Pages hosts this guide and downloads; it does not run the receiver. The receiver itself does not forward data or submit business jobs.

  1. ZIP을 쓰기 가능한 폴더에 풉니다. Python 3.10 이상이 필요합니다.
  2. Windows는 start.cmd를 실행합니다. macOS/Linux는 sh start.sh입니다. 최초 실행 시 가상환경과 PyPI 의존성을 설치합니다.
  3. 실행 창을 유지하고 http://127.0.0.1:19494/를 엽니다. 관리자 권한, DLL, 페어링키, 확장 ID 등록은 필요하지 않습니다.

확장과 별도로 수신부를 실행해야 합니다. GitHub Pages는 안내와 다운로드만 제공하며 수신부를 대신 실행하지 않습니다. 수신부 자체는 외부 전달이나 업무 접수를 하지 않습니다.

2. Connect, apply, generate, verify

2. 연결 → 적용 → 생성 → 확인

  1. In DOM Router, open Connections → Quick connect, enter the WebSocket address below, click Connect and grant access to the local receiver.
  2. Download GenQRCode → WS JSON below or from the receiver dashboard. In the extension, import the profile, select local-ws-demo, save, then click Apply / reload. Grant access to https://genqrcode.com.
  3. Open GenQRCode, choose URL, enter https://example.com/dom-router-review, then click Generate QR Code.
  4. Check the receiver's stored events for the same URL, generated: true, imageFormat: svg, an event ID and received timestamp. Connecting alone does not start observation; the profile must be applied.

If another GenQRCode profile already owns this source, stop it before applying the imported profile, or update that existing profile's connection. Importing a template only creates a draft.

  1. 확장의 연결 → 빠른 연결에 아래 WS 주소를 입력하고 연결합니다. 로컬 수신 주소의 권한을 허용합니다.
  2. 아래 또는 수신부 화면에서 GenQRCode → WS JSON을 받습니다. 확장에 불러와 local-ws-demo를 선택하고 저장 → 적용 / reload를 누릅니다. genqrcode.com 권한을 허용합니다.
  3. GenQRCode의 URL 탭에서 https://example.com/dom-router-review를 입력하고 QR 코드 생성을 누릅니다.
  4. 수신부의 저장 기록에서 같은 URL과 generated: true, imageFormat: svg, 이벤트 ID·수신 시각을 확인합니다. 연결만으로 감지가 시작되지는 않습니다.

같은 소스의 GenQRCode 프로필을 이미 사용 중이면 기존 프로필을 중지하거나 기존 프로필의 연결을 변경해 적용하세요. 템플릿 불러오기는 초안 생성이며 적용과 다릅니다.

Review scope and data handling

검증 범위와 데이터 처리

DOM Router's single purpose is user-configured browser-to-local data integration. The extension package also includes local DOM/callback/network examples and LG/SK business-specific templates. Those business templates require authorized accounts on their respective sites. No business-site test credentials are supplied here; this public example demonstrates the shared engine and event delivery, not every restricted business workflow.

Profiles configure packaged detection, validation, extraction and event blocks. They do not contain executable JavaScript. The extension and the receiver are separate programs; neither this guide nor the review receiver supplies a remote command-execution service.

This receiver is an unencrypted loopback HTTP/WS diagnostic sample. It accepts only demo / GENERIC / diagnostic.observed events, and qrUrl is restricted to example.com or example.invalid. Use synthetic values only; it is not a production receiver for personal or authentication data. This sample does not establish compliance for the extension's handling of other data.

Stored events remain local in SQLite and are bounded by retention limits. The receiver has a Clear action and JSON export. Clearing the receiver does not clear the extension's own queue/logs or separately exported files. The receiver never forwards data to DoriDori or another external service. A separate receiving program used in production may have its own data practices; see the extension's privacy policy.

DOM Router의 단일 목적은 사용자가 설정한 웹-로컬 데이터 연동입니다. 확장 패키지에는 로컬 DOM·콜백·네트워크 예제와 LG/SK 업무 템플릿도 포함됩니다. 업무 템플릿에는 각 사이트의 정당한 접근 권한과 계정이 필요합니다. 이 페이지는 업무 사이트 계정을 제공하지 않으며 공개 예제로 공통 엔진과 전달 경로를 검증합니다. 모든 제한 업무 절차를 시연한 것은 아닙니다.

프로필은 패키지에 구현된 감지·검증·추출·이벤트 블록의 설정이며 실행 JavaScript를 포함하지 않습니다. 확장과 수신부는 별도 프로그램이며 원격 명령 실행 서비스를 제공하지 않습니다.

수신부는 평문 HTTP/WS 루프백 진단 예제입니다. demo / GENERIC / diagnostic.observed만 허용하고 qrUrl은 example.com 또는 example.invalid로 제한합니다. 합성 값만 사용하세요. 실제 개인정보·인증정보 운영 수신부가 아니며 확장의 다른 데이터 처리에 대한 정책 준수까지 보증하지 않습니다.

이벤트는 SQLite에 보관하며 삭제·JSON 내보내기를 제공합니다. 수신부 삭제는 확장 자체의 대기열·로그와 별도로 내보낸 파일을 삭제하지 않습니다. 수신부는 DoriDori 등 외부 서비스로 전달하지 않습니다. 운영용 수신 프로그램의 후속 처리는 별도 정책을 확인해야 합니다.

Troubleshooting / 오류 확인
  • WS_CONNECTION_FAILED: start the receiver, confirm 127.0.0.1 and port 19494.
  • Connected but no event: save and apply the profile; inspect extension logs and requested site permissions.
  • SOURCE_OWNERSHIP_CONFLICT: stop the profile already observing the same source.
  • SVG_CONTENT_TYPE_INVALID: inspect the public site's actual response; do not treat it as a successful generation.
  • PUBLIC_EXAMPLE_URL_REQUIRED / REVIEW_DIAGNOSTIC_ONLY: use public/synthetic examples rather than production profiles.
  • Port conflict: start.cmd --port 19495; change endpoints and download fresh DOM profiles from that receiver.
