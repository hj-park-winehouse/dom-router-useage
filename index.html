DOM Router documentation

DOM Router 문서

Read selected web data. Connect it to your local program.

선택한 웹 데이터를 읽고, 내 컴퓨터의 프로그램에 연결하세요.

DOM Router is a Chrome extension for user-configured browser-to-local data integration. Build a profile with packaged detection, extraction, validation and delivery blocks, then inspect the resulting JSON events.

DOM Router는 사용자가 설정한 웹페이지의 데이터를 로컬 프로그램에 전달하는 Chrome 확장입니다. 감지·추출·검증·전달 블록으로 프로필을 구성하고 JSON 이벤트의 처리 결과를 확인합니다.

What you can configure

설정할 수 있는 것

Choose a site, define the observation source, select fields, add guards and route events to a local WebSocket or HTTP receiver. Profiles can be imported and exported as JSON. The extension provides connection status, recovery and execution logs.

사이트와 감지 소스를 정하고 필요한 필드를 선택한 뒤 조건을 검증해 로컬 WebSocket 또는 HTTP 수신부로 전달합니다. 프로필은 JSON으로 불러오거나 내보낼 수 있으며 연결 상태·복구와 실행 로그를 제공합니다.

A separate local receiver is required. This site provides documentation and downloads; GitHub Pages does not run the receiver.

데이터를 받으려면 별도의 로컬 수신 프로그램이 필요합니다. 이 사이트는 문서와 다운로드를 제공하며 수신부를 대신 실행하지 않습니다.

Start the local receiver

로컬 수신 프로그램 실행

  1. Download and extract the ZIP to a writable folder. Install Python 3.10 or later if needed.
  2. Windows: double-click start.cmd. macOS/Linux: run sh start.sh. The first run creates a virtual environment and installs dependencies from PyPI.
  3. Keep the terminal running and open http://127.0.0.1:19494/. No administrator access, DLL, pairing key or extension ID registration is required.

DOM Router requires a separately running receiver to deliver events. GitHub Pages hosts this guide and downloads; it does not run the receiver. The receiver itself does not forward data or submit business jobs.

  1. ZIP을 쓰기 가능한 폴더에 풉니다. Python 3.10 이상이 필요합니다.
  2. Windows는 start.cmd를 실행합니다. macOS/Linux는 sh start.sh입니다. 최초 실행 시 가상환경과 PyPI 의존성을 설치합니다.
  3. 실행 창을 유지하고 http://127.0.0.1:19494/를 엽니다. 관리자 권한, DLL, 페어링키, 확장 ID 등록은 필요하지 않습니다.

확장과 별도로 수신부를 실행해야 합니다. GitHub Pages는 안내와 다운로드만 제공하며 수신부를 대신 실행하지 않습니다. 수신부 자체는 외부 전달이나 업무 접수를 하지 않습니다.

Connect, apply, generate, verify

연결 → 적용 → 생성 → 확인

  1. In DOM Router, open Connections → Quick connect, enter the WebSocket address below, click Connect and grant access to the local receiver.
  2. Download GenQRCode → WS JSON below or from the receiver dashboard. In the extension, import the profile, select local-ws-demo, save, then click Apply / reload. Grant access to https://genqrcode.com.
  3. Open GenQRCode, choose URL, enter https://example.com/dom-router-review, then click Generate QR Code.
  4. Check the receiver's stored events for the same URL, generated: true, imageFormat: svg, an event ID and received timestamp. Connecting alone does not start observation; the profile must be applied.

If another GenQRCode profile already owns this source, stop it before applying the imported profile, or update that existing profile's connection. Importing a template only creates a draft.

  1. 확장의 연결 → 빠른 연결에 아래 WS 주소를 입력하고 연결합니다. 로컬 수신 주소의 권한을 허용합니다.
  2. 아래 또는 수신부 화면에서 GenQRCode → WS JSON을 받습니다. 확장에 불러와 local-ws-demo를 선택하고 저장 → 적용 / reload를 누릅니다. genqrcode.com 권한을 허용합니다.
  3. GenQRCode의 URL 탭에서 https://example.com/dom-router-review를 입력하고 QR 코드 생성을 누릅니다.
  4. 수신부의 저장 기록에서 같은 URL과 generated: true, imageFormat: svg, 이벤트 ID·수신 시각을 확인합니다. 연결만으로 감지가 시작되지는 않습니다.

Core concepts

Profiles & blocks

프로필과 기능 블록

A profile defines where to observe data and how to turn it into an event.

프로필은 어디서 데이터를 감지하고 어떤 이벤트로 만들지 정의합니다.

The processing pipeline

처리 흐름

01

Observe

감지

Select DOM changes, a specified page callback, or selected request/response fields.

DOM 변화, 지정 함수의 콜백 또는 지정 요청·응답을 감지 소스로 정합니다.

02

Validate

검증

Check required fields and response conditions before continuing.

필수 값과 응답 조건을 검사하고 조건이 맞을 때만 다음 단계로 진행합니다.

03

Extract

추출

Map selected values into named variables.

선택한 값을 이름이 있는 변수에 저장합니다.

04

Emit & deliver

이벤트 생성·전달

Bind the variables to a JSON event and send it through the selected connection.

변수를 JSON 이벤트 필드에 연결하고 선택한 연결로 보냅니다.

GenQRCode example

GenQRCode 예제

The supplied profile observes POST /preview on genqrcode.com. It selects the URL from the generation request, checks HTTP 200 and a valid SVG response, then emits diagnostic.observed. It does not decode a QR image or click Generate automatically.

제공된 프로필은 genqrcode.com의 POST /preview를 감지합니다. 생성 요청의 URL을 선택하고 HTTP 200과 유효한 SVG 응답을 확인한 뒤 diagnostic.observed를 생성합니다. QR 이미지를 디코딩하거나 생성 버튼을 자동으로 클릭하지 않습니다.

Save is not apply

저장과 적용은 다릅니다

Import a profile or template, select its connection, save, then choose Apply / reload. Grant the requested site permission. If another profile owns the same source, stop that profile first.

프로필 또는 템플릿을 불러오고 연결을 선택한 뒤 저장 → 적용 / reload를 누릅니다. 사이트 접근 권한을 허용하세요. 같은 소스를 사용하는 기존 프로필이 있다면 먼저 중지합니다.

Profiles configure blocks already implemented in the extension package. They do not contain executable JavaScript.

프로필은 확장 패키지에 구현된 블록의 설정이며 실행 JavaScript를 포함하지 않습니다.

Understand delivery status

전달 상태 이해

WebSocket keeps a connection open. HTTP sends individual requests and has no persistent WS-client count. A connected receiver does not mean a profile is applied.

WebSocket은 연결을 유지하고 HTTP는 개별 요청을 보냅니다. HTTP는 상시 WS 연결 개수로 상태를 판단하지 않습니다. 수신부 연결과 프로필 적용은 별도입니다.

A successful extension send does not prove durable storage or business completion. Confirm the event in the receiver. This Python receiver commits to SQLite before returning its storage reply; the generic extension WS sender does not wait for that reply as a durable acknowledgment.

확장의 전송 성공만으로 DB 저장이나 업무 완료를 확정할 수 없습니다. 수신부에서 이벤트를 확인하세요. Python 수신부는 SQLite 저장 후 응답하지만 범용 확장 WS 전송부는 이 응답을 영구 저장 ACK로 기다리지 않습니다.

Receiver storage reply

수신부 저장 응답

{
  "stored": true,
  "eventId": "<event UUID>",
  "duplicate": false,
  "sequence": 1
}

The same event ID with identical content is deduplicated. Reusing an ID with different content is rejected with HTTP 409. This reply is receiver behavior, not a business-job status.

동일 ID와 동일 내용은 중복 저장하지 않습니다. 같은 ID에 다른 내용을 보내면 HTTP 409로 거절합니다. 이 응답은 수신부 저장 결과이며 업무 작업 상태가 아닙니다.

Troubleshooting

문제 해결

Follow the event from receiver connection to stored record.

수신부 연결부터 저장 기록까지 순서대로 확인합니다.

Receiver is unreachable

수신부 연결 실패

WS_CONNECTION_FAILED

Keep start.cmd running and check 127.0.0.1, the port and the full endpoint path.

start.cmd 실행 창이 유지되는지, 주소·포트·전체 경로가 맞는지 확인합니다.

Connected, but no event

연결됐지만 이벤트가 없음

NO_EVENT

Check site permissions, the selected connection and Apply / reload. Saving alone does not activate observation.

사이트 권한과 선택한 연결, 적용 / reload를 확인합니다. 저장만으로 감지가 시작되지는 않습니다.

Source already in use

다른 프로필이 감지 중

SOURCE_OWNERSHIP_CONFLICT

Stop the profile already observing the source, then apply the intended one.

같은 소스를 감지하는 기존 프로필을 중지한 뒤 원하는 프로필을 적용합니다.

Unexpected site response

예상과 다른 사이트 응답

SVG_CONTENT_TYPE_INVALID

Inspect the website response. Do not report a successful QR generation if the SVG check fails.

사이트의 응답을 확인합니다. SVG 검증이 실패했다면 QR 생성 성공으로 판단하지 않습니다.

Use the public example URL

공개 예제 URL 사용

PUBLIC_EXAMPLE_URL_REQUIRED

Enter https://example.com/dom-router-review. Do not send a live authentication URL.

https://example.com/dom-router-review를 입력합니다. 실제 인증 URL은 보내지 않습니다.

Wrong event type or profile

예제와 다른 이벤트·프로필

REVIEW_DIAGNOSTIC_ONLY

Use the supplied GENERIC / demo / diagnostic.observed profiles, not a production business profile.

제공된 GENERIC / demo / diagnostic.observed 프로필을 사용합니다.

Port already in use

포트가 이미 사용 중

PORT_IN_USE

Run start.cmd --port 19495, change the connection endpoint and download fresh DOM profiles from that receiver dashboard.

start.cmd --port 19495로 실행하고 연결 주소를 변경합니다. 새 수신부 화면에서 DOM 프로필을 다시 받습니다.
